# Kokoro Speech Studio v3

Local-first FastAPI + HTML/CSS/JavaScript UI for Kokoro-82M. The app expects the project model layout to contain `models/kokoro-v1_0.pth`, `models/config.json`, and `models/voices/*.pt`.
A proper webui for kokoro tts with, language, voices and gender separation and statistics for nerds included.

My opinion : in general i think, kokoro tts is better than kittentts, it gives more natural sounding voice, and diversity and interestingly i personally found it to be faster on my laptop. 

i did not upload voices and outputs for this like i did for kittentts because you can find and listen to all the voices here https://rewind.ai/voices/ before you download the model.
