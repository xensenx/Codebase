WebTools is a collection of small, practical browser-based tools built from projects and utilities in the Codebase repository. It brings together useful standalone web tools in one simple place, with each tool designed to run directly in the browser without requiring a separate installation. The collection may include active tools, experiments, and older utilities that remain useful. New tools can be added over time as they are prepared for web use. Visit the WebTools site at https://xensenx.github.io/Codebase/
