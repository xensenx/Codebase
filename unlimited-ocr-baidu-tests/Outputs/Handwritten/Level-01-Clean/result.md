Introduction
What is machine learning?
Machine learning is a branch of artificial intelligence that develops algorithms by learning the hidden patterns of the datasets used it to make predictions on new similar type data, without being explicitly programmed for each task.
A computer program which learns from experience is called a machine learning program on simply a learning program.
Machine learning is used in many different applications, from image and speech recognition to natural language processing recommendation systems, fraud detection, postfolio optimization, automated risk and so on. Machine learning models also also used to power autonomous vehicles, drones and robots, making them more intelligent and adaptable to changing environments.
